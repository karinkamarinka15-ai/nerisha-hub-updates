# NERISHA HUB Updates

Публичный канал обновлений приложения NERISHA HUB.

Здесь публикуются официальные APK-релизы. Приложение проверяет последний релиз и предлагает обновление, если его версия выше установленной.

## Публикация обновлений

Сборка приложения выполняется в приватном репозитории `neRishaStudio`. Для публикации APK в этот репозиторий workflow сборки использует секрет `UPDATES_REPO_TOKEN`.

В приватном репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

- **Name:** `UPDATES_REPO_TOKEN`
- **Secret:** Personal Access Token с правом **Contents: Read and write** только для этого репозитория.

После этого workflow сможет создавать здесь релизы с файлом `NERISHA-HUB.apk`.

Формат описания релиза:
```
versionCode: 29
SHA256: <64-символьная SHA-256 сумма APK>

Краткое описание изменений.
```

Не загружайте сюда исходники приложения или пользовательские аудиофайлы.
